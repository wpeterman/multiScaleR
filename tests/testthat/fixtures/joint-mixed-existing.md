This small fixture contains only the existing data and binned inputs extracted
from tools/benchmarks/bayesian_scales/annual-smoke.rds ($inputs), October 23, 2026.
No posterior draws or fitted objects are included. Row names are set to the
existing unique key column. It has 120 observations from 24 sites and five years.
The tests fit a common-scale frequentist model, not the Bayesian annual-scale
model. This is a numerical integration regression fixture, not a coverage study.
