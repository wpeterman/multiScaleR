## Ordered implementation batches

   stream kernel engine with `standardize = FALSE`, fixed response-design
   compiler and normalized binomial likelihood. Add an explicit supported
   context instead of requiring private access or fabricated cell lists.
   Distinguish value-only evaluation from derivative and inference availability.
   Retain actual coefficient-fit warnings, score/rank checks and failures.
   The public prepared interface must bind real feature sources, provider
   versions, coordinate/row identities, response/trial/weight/offset semantics,
   model columns and physical reference recipes. Coefficients and mutable fit
   state belong to each response/model, not a shared feature cache.

2. **Finite coefficient existence and exact target qualification.** Solver
   convergence, finite returned coefficients and full rank do not by themselves
   supply the memo's independent finite-MLE certificate. Define explicit
   finite/nonexistent/unknown outcomes and a retained witness before admitting
   new selection results. Compare raw features, fixed physical ns2 designs,
   coefficient optima, predictions and normalized Bernoulli NLL with the native
   route at references, asymmetric scales, bounds and exact retained vectors.
   Retain all failed, nonfinite, unknown and lower attempted points. Port the
   existing analysis certificates; do not replace them with a convergence flag.

3. **Opt-in raw/reference smooth analytic fitting.** Connect explicit raw
   transforms through `multiScale_optim`, profile contract, derivative engine,
   prediction metadata and appropriate downstream methods. Freeze one
   predictor-only interior knot and both boundary knots from the declared
   500 m reference in physical units. Use identical forest/developed recipes
   for matched amount and metric families. Validate value, first and second
   smooth-coordinate chain rules, reference/stream equivalence, factors and
   cross terms. Do not infer a new reference at each trial scale or silently
   reinterpret old standardized knots. Other analytic/Bayesian targets retain
   their own existing admission and normalization rules until qualified.

4. **Exact hard-radius hybrid optimizer.** Put native MI/ED radius evaluation
   in an outer discrete/finite-direction search; profile only smooth Gaussian
   bandwidths and binomial coefficients inside each radius. Derivative
   coordinates must be explicit. Preserve exact cell/window/rook-edge laws,
   ties, event inclusion and behavior immediately below, at and above events.
   Retain original candidate minima, independent/cold attempts, bounds and
   multiple-basin evidence. Failed/unknown candidates cannot disappear from
   denominators or best-point eligibility. Do not report a hard-radius Hessian
   confidence interval or claim a global optimum from numerical convergence.

   validated geometry/event arrays from response-specific fitting. Authenticate
   finite sorted arrays and canonical point ordering once, then qualify any
   omission of repeated `findInterval` sorted/NA checks against the original
   default-check implementation. Preserve native binary search and tie rules.
   Use explicit byte/entry limits and complete scientific cache keys. Prove

   Do not copy the 99.231 GiB store or retain full candidate arrays/checkpoints.

6. **Prediction, selection and validation integration.** Retain physical-unit
