# Example data frame

Example count data to be used vignette document example

## Usage

``` r
data(landscape_counts)
```

## Format

A data frame with 100 rows and 2 columns. Data were simulated from a
Poisson distribution with an intercept of 0.25; land1 effect = -0.5;
site effect = 0.3; land2 effect = 0.7. True simulated Gaussian scale
effects (sigma): land1 = 250; land2 = 500. For use with package
vignette.

- counts:

  –\> Simulated counts at spatial locations

- site:

  –\> A habitat variable measured at the site
